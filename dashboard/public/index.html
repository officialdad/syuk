Setting Up a New Cone

1
Power on the ESP32

Plug in via USB-C (power bank or laptop). LED shows blue = initializing. The cone creates a WiFi network: SmartCone-xxxx

WiFi Hotspot must use 2.4 GHz

ESP32 does not support 5 GHz. Go to Hotspot Settings → Band → select 2.4 GHz.

2
Connect to the cone's WiFi

Method A: Connect to "SmartCone-xxxx" WiFi, then open:

Open Cone Portal (192.168.4.1)

Method B: Connect to "SmartCone-xxxx" → phone shows "No internet" → tap the network → tap cog icon → "Manage router"

3
Configure WiFi credentials

Using phone hotspot? Turn OFF hotspot first → connect to cone → enter hotspot SSID + password → Save → turn hotspot back ON. ESP32 auto-connects within seconds.

Using site WiFi? Just enter the WiFi name and password.

4
Set Cone ID

Auto-generated ID (e.g. cone-a7f3) is pre-filled. Change it if you want a custom name. Tap Save.

5
Place on map

Dashboard shows "New Cone Detected" toast. Click "Place Now" or enter the Cone ID below and click "Use My GPS Location".
